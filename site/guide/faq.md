# 常见问题

## 跨午夜怎么办？

新文件日期取 PR 首次创建时的北京时间。若午夜后才提交，请从同步后的 main 新建分支，重新生成今天的文件并复制正文，当天重新开 PR。已在当天打开的 PR 可以隔天合并。

## 为什么检查失败？

点检查的 **Details** 阅读原因。每个 PR 只允许编辑或新增本人一份日记，文件名是小写用户名。分支落后时在 PR 页选择 **Update branch**。若 GitHub 用户名变更，请联系维护者核对历史归属。

## 数据如何计算？

每个记录日期算一天。同一天多人写日记，在公共日历上点亮同一格。累计和最长连续天数覆盖全部年份。当前连续允许今天尚未完成的记录衔接到昨天，日期均按北京时间判断。

## 日记会公开吗？

所有人都可以阅读、克隆和查看提交历史。请勿提交密码、密钥、地址或他人的隐私。删除文件后，历史和副本仍可能保留。日记版权归作者，转载或商用需取得相应授权。
